AWS Architecture Map
🪣
Amazon S3
Object storage — hosts uploaded images and processed thumbnails in uploads/ and processed/ prefixes.
⚡
AWS Lambda
Event-driven compute — triggered by S3 ObjectCreated event. Runs Python 3.12 with Pillow to resize images to 200×200 px.
📊
CloudWatch Logs
Centralized logging for all Lambda executions — includes timing, error traces, and processing metrics.
🔑
AWS IAM
Least-privilege role grants Lambda only s3:GetObject and s3:PutObject on the target bucket.
